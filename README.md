# PAI2-STX — BYODSEC

## 1. Objetivo

Desarrollar y evaluar un laboratorio de acceso remoto seguro mediante una VPN Road Warrior, una infraestructura de clave pública (PKI), certificados X.509 y autenticación mutua.

## 2. Entorno de desarrollo

- Sistema anfitrión: Windows.
- Máquina virtual: Kali Linux 2026.2.
- Virtualización: Oracle VirtualBox.
- Editor: Visual Studio Code.
- Control de versiones: Git y GitHub.
- VPN prevista: OpenVPN Community.

## 3. Estado del proyecto

- [x] Preparación inicial del entorno.
- [ ] Diseño y documentación de la arquitectura.
- [ ] Creación de la PKI y los certificados.
- [ ] Configuración de la VPN.
- [ ] Autenticación y autorización de usuarios.
- [ ] Pruebas de seguridad y auditoría.
- [ ] Medición del rendimiento.
- [ ] Memoria y entrega final.

## 4. Seguridad

No se deben incluir en el repositorio contraseñas, claves privadas, credenciales ni configuraciones que contengan secretos.

## 5. Despliegue

Las instrucciones de instalación y ejecución se documentarán a medida que se implemente y verifique el laboratorio.
